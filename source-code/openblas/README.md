# OpenBLAS

On HPC, OpenBLAS is one of the most widely used BLAS libraries. It is a
high-performance implementation of the Basic Linear Algebra Subprograms (BLAS)
API, which provides routines for performing basic vector and matrix operations.


## What is it?

1. `dgemm.c`: application to illustrate how to call the `dgemm` function from
   (Open)BLAS.
1. `CMakeLists.txt`: CMake file to build the application.

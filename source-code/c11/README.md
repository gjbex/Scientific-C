# C11

The C11 specification added some intesting features to the C language, including:
- `_Generic` keyword for type-generic programming
- Static assertions with `static_assert`
- Thread support with `<threads.h>`
- Improved Unicode support with `<uchar.h>`
- Anonymous structures and unions
- Improved type-generic macros in `<tgmath.h>`
- New standard library functions like `aligned_alloc`, `timespec_get`, and `atomic` operations
- Improved support for multithreading and atomic operations


## What is it?

1. `generic`: illustration of using the `_Generic` keyword for type-generic programming.

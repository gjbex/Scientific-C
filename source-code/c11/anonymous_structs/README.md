# Anonymous structures

C11 introduced anonymous structures, which allow you to define a structure
without giving it a name. This can be useful for creating simple data
structures without the need for a separate type definition.  The addition to
the standard was mainly intended to include compiler extensions that were
already widely used.


## What is it?

1. `points.c`: application illustrating the use of anonymous structures as well as
   `_Generic`..
1. `CMakeLists.txt`: CMake file for the application.
